# pixel-art-auto-captioner

Scaffold for a pixel-art dataset auto-captioning project.

The long-term goal is a maintainable pipeline for image ingestion, caption generation, model comparison, batch processing, and dataset export for future AI training workflows.

## Current status

This repository is in a setup/scaffolding phase.

- `main.py` contains an existing monolithic JoyCaption/LLaVA prototype.
- New project structure, Pi instructions, and workflow documentation have been added.
- No new captioning pipeline logic has been implemented in the scaffold.
